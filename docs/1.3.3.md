# NeoTab 1.3.3

`1.3.3` is a focused scoreboard-interoperability patch for the `1.3.x` feature line.

## Fix

- Treats another plugin's scoreboard takeover as temporary rather than a permanent per-player opt-out.
- Continues evaluating the configured NeoTab scoreboard state during normal update ticks without fighting an active external owner.
- Reuses the existing NeoTab session when a temporary sidebar plugin restores NeoTab's known board.
- Creates a fresh NeoTab session when the external plugin restores an empty, available board.
- Clears temporary ownership state when the player explicitly disables the NeoTab scoreboard.

## Tests and validation

- Adds regression coverage for active external ownership, restoration of the known NeoTab board, and restoration of a free board.
- Clean Gradle build and all regression tests pass without deprecation warnings.

## Compatibility

- Paper `1.20.6+`
- Java 21 bytecode
- LuckPerms, PlaceholderAPI, WorldEdit, and FastAsyncWorldEdit remain optional.
