# NeoTab 1.4.2 local validation

Date: 2026-09-05. No push, tag or public release was performed.

The complete Java-21 Gradle build and platform compatibility check passed with 65 tests (51 existing + 14 hotfix regressions). The integrated 1.5.0 development snapshot passed its complete build and 105 tests.

Each run checked plugin enablement/version, reload, retained region listing, refusal to overwrite intentionally corrupted config and region files, repair followed by successful persistence, nearest-player toggles and clean shutdown. The intentionally rejected reloads log errors by design. No unexpected NeoTab enable/disable, scheduled-task or command exceptions were observed.

The provided Paper 26.2 development build (`26.2-10-dev`, API `26.2.build.10-alpha`) cannot initialize the supplied PlaceholderAPI 2.12.2 JAR: PlaceholderAPI itself throws `NumberFormatException` while parsing the server version. NeoTab continues with LuckPerms and without PlaceholderAPI. A separate Paper 1.21.11 run confirms that both integrations enable successfully with the final 1.4.2 JAR; the 1.5.0 snapshot also passes with both there. No third-party plugin or original server was modified.

No Minecraft client was connected. GUI rendering/click appearance, client-side tab/ActionBar appearance, live placeholder values and large-player-count TPS/MSPT were not measured. GUI scheduling, visibility, timing and chat races are covered through deterministic API-level regression tests.

All six runtime tests used JARs byte-identical to the final artifacts. Tests ran one server at a time in freshly created local-only server folders, and all started server processes exited. Original server directories were used only as sources for runtime copies.
