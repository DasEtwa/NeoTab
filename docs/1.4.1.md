# NeoTab 1.4.1 — unreleased test build

`1.4.1` is currently intended for private testing and has not been released.

## Fixes

- Applying `metrics.enabled` with `/tab reload` now starts or stops bStats without requiring a server restart.
- ActionBar message durations now use monotonic elapsed time, so operating-system clock corrections cannot expire or extend them. The optional visible clock continues to use the configured real-world time zone.
- Region-priority buttons clamp at Java's integer limits instead of wrapping from the highest value to the lowest value or back.
- The Gradle wrapper is executable on Linux, matching the documented `./gradlew build` command.
