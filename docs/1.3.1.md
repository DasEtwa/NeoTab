# NeoTab 1.3.1

`1.3.1` is a stable patch release for the `1.3.0` feature line.

## Fixes

- Prevents a delayed scoreboard join update from recreating a session after a player has quit.
- Makes ActionBar messages with equal priority resolve deterministically by source name.
- Restricts ActionBar command tab completions to players with the matching module permission.

## Compatibility

- Paper `1.20.6+`
- Java 21 bytecode
- LuckPerms, PlaceholderAPI, WorldEdit, and FastAsyncWorldEdit remain optional.

## Validation

- Clean Gradle build completed successfully.
- Multi-server startup and NeoTab enablement checked across the local Paper test network.
- RCON validation completed on all reachable backends with `/version NeoTab`, `/tab reload`, and `/tab sb list`.
